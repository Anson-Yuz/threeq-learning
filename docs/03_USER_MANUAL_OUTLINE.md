# 用户操作手册大纲

## 1. 学生使用手册

### 1.1 首次使用

1. 开机。
2. 连接网络。
3. 登录账号。
4. 绑定学生档案。
5. 选择年级和学科。
6. 下载基础学习资源。

### 1.2 今日学习

1. 查看今日任务。
2. 开始课程。
3. 继续上次学习。
4. 完成练习。
5. 查看任务完成状态。

### 1.3 课程学习

1. 进入课程中心。
2. 按学科筛选课程。
3. 下载课程。
4. 播放课程。
5. 查看学习进度。

### 1.4 练习与测验

1. 开始练习。
2. 作答题目。
3. 标记不确定题。
4. 提交答案。
5. 查看解析。
6. 加入错题本。

### 1.5 错题复习

1. 进入错题本。
2. 按知识点筛选。
3. 查看错因。
4. 重新练习。
5. 完成复习。

### 1.6 学习报告

1. 查看今日报告。
2. 查看周报告。
3. 查看薄弱知识点。
4. 查看进步趋势。

### 1.7 离线学习

1. 下载课程资源。
2. 断网后继续学习。
3. 查看同步状态。
4. 联网后自动同步。
5. 同步失败后手动重试。

### 1.8 常见问题

- 忘记密码。
- 无法登录。
- 课程无法播放。
- 题目提交失败。
- 学习记录未同步。
- 设备空间不足。

## 2. 家长使用手册

### 2.1 绑定学生

1. 登录家长账号。
2. 扫码或输入绑定码。
3. 确认学生信息。

### 2.2 查看报告

1. 查看学习时长。
2. 查看课程完成情况。
3. 查看错题和薄弱点。
4. 查看系统建议。

### 2.3 设置学习计划

1. 设置每日学习时长。
2. 设置学科优先级。
3. 设置休息提醒。
4. 设置内容限制。

### 2.4 设备管理

1. 查看绑定设备。
2. 解除绑定。
3. 清理缓存。
4. 查看版本。

## 3. 教师/管理员使用手册

### 3.1 学生管理

1. 创建班级。
2. 添加学生。
3. 分配课程。
4. 查看学习状态。

### 3.2 任务下发

1. 选择学生或班级。
2. 选择课程或题目。
3. 设置完成时间。
4. 发布任务。
5. 查看完成情况。

### 3.3 内容管理

1. 上传课程。
2. 管理题库。
3. 绑定知识点。
4. 设置难度。
5. 发布资源包。

### 3.4 学情分析

1. 班级概览。
2. 学生详情。
3. 知识点掌握。
4. 错题排行。
5. 导出报告。

## 4. 运维手册

### 4.1 发布流程

1. 创建 release 分支。
2. 更新版本号。
3. 执行自动化检查。
4. 构建产物。
5. 灰度发布。
6. 观察监控指标。
7. 全量发布。

### 4.2 回滚流程

1. 确认问题范围。
2. 暂停发布。
3. 回滚配置或资源。
4. 必要时回滚应用版本。
5. 发布故障说明。
6. 复盘并创建修复 Issue。

### 4.3 监控处理

1. 崩溃率升高。
2. 登录失败率升高。
3. 课程下载失败。
4. 答题提交失败。
5. 同步队列积压。
6. 服务端接口超时。

## 5. 手册验收要求

每个功能上线前必须满足：

1. 有入口说明。
2. 有操作步骤。
3. 有截图。
4. 有异常处理。
5. 有常见问题。
6. 与实际 UI 一致。
