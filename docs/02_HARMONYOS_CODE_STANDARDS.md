# HarmonyOS 代码规范

## 1. 总原则

1. 以 ArkTS、ArkUI、Stage 模型、HarmonyOS SDK 推荐能力为准。
2. 优先使用系统组件和系统能力，避免自行实现已有基础能力。
3. 业务代码分层清楚，页面不承担网络、数据库、复杂业务规则。
4. 所有功能必须考虑权限、异常、离线、同步、日志和测试。

## 2. ArkTS 规范

1. 明确类型，禁止无理由使用 `any`。
2. 公共模型使用 `interface`、`class` 或明确的类型定义。
3. 网络 DTO 与业务模型分离。
4. 避免在 UI 组件中写复杂数据转换。
5. 异步调用统一使用 `async/await` 或项目约定风格，不混乱嵌套。
6. 错误统一转换为业务错误模型。
7. 常量集中管理。
8. 工具函数必须纯净、可测试。

## 3. ArkUI 组件规范

1. 页面组件只组织布局和状态。
2. 复杂页面拆为 Header、Content、Footer、Card、Dialog 等局部组件。
3. 公共组件只接收 props 和事件回调，不直接访问业务仓储。
4. 禁止大量硬编码颜色、字号、间距。
5. 统一从主题 token 获取视觉参数。
6. 列表必须考虑长列表性能、空状态和刷新状态。
7. 弹窗必须有取消、确认、关闭和返回键策略。
8. 表单必须有校验、错误提示和提交中状态。
9. 图片必须有占位、失败图和尺寸约束。
10. 页面必须适配不同屏幕尺寸。

## 4. 状态管理规范

按范围选择状态：

1. 组件内临时状态：使用组件本地状态。
2. 父子组件共享状态：使用 ArkUI 推荐的双向或单向状态传递机制。
3. 页面级状态：放在页面 ViewModel 或状态对象中。
4. 应用级状态：使用应用级存储或统一状态中心。
5. 持久状态：使用持久化存储，不能只放内存。

禁止：

- 多个页面各自维护同一份关键业务状态。
- 页面直接修改全局对象导致不可追踪副作用。
- 把接口响应原样塞进 UI。

## 5. 路由与导航规范

1. 使用统一路由注册表。
2. 路由名、参数、返回值必须类型化。
3. 页面跳转必须检查登录态、权限和必要参数。
4. 深链或外部入口必须做参数校验。
5. 返回栈策略必须清晰。

## 6. 网络规范

1. 网络请求统一封装。
2. 鉴权 token 统一注入。
3. 错误码统一映射。
4. 请求超时、重试、取消必须有策略。
5. 弱网和断网必须有用户可理解的提示。
6. 接口版本必须可控。
7. 禁止在页面直接调用底层 HTTP 能力。

## 7. 本地存储规范

1. 学习记录、离线队列、课程缓存、用户配置分开存储。
2. 敏感数据加密或使用系统安全能力。
3. 本地数据结构必须有版本号。
4. 数据迁移必须可回滚或可重试。
5. 缓存清理不能误删未同步数据。

## 8. 权限与隐私规范

1. 只申请必要权限。
2. 权限申请前说明用途。
3. 用户拒绝权限后提供替代流程。
4. 日志不得输出手机号、token、学生真实姓名、详细答题隐私等敏感信息。
5. 儿童数据必须最小化采集。
6. 隐私政策和用户手册必须说明数据用途。

## 9. 日志与埋点规范

日志分级：

- `debug`: 本地调试。
- `info`: 关键流程。
- `warn`: 可恢复异常。
- `error`: 功能失败或不可恢复异常。

埋点必须覆盖：

- 页面打开。
- 学习任务开始和完成。
- 课程开始和完成。
- 答题提交。
- 错题复习。
- 报告打开。
- 同步成功和失败。
- 崩溃和关键异常。

埋点字段必须脱敏。

## 10. 测试规范

每个核心模块必须包含：

1. 正常路径测试。
2. 空数据测试。
3. 错误输入测试。
4. 网络失败测试。
5. 离线测试。
6. 权限失败测试。
7. 数据迁移测试。

核心学习闭环必须有端到端自动化测试。

## 11. 性能规范

1. 首页首屏必须控制加载时间。
2. 长列表使用懒加载或分页。
3. 图片按尺寸加载。
4. 大资源异步下载。
5. 离线资源下载必须可暂停、可恢复、可重试。
6. 避免 UI 线程执行重计算。
7. 包体积纳入 CI 检查。

## 12. 安全规范

1. 密钥不入库。
2. 签名证书不入库。
3. Token 不写日志。
4. 接口必须走 HTTPS。
5. 本地敏感数据加密。
6. 用户身份过期必须安全退出。
7. 管理端接口必须做权限校验。

## 13. 代码审查清单

PR 审查必须确认：

- 是否使用 ArkUI 原生组件。
- 是否符合分层结构。
- 是否有硬编码样式。
- 是否有异常状态。
- 是否有离线处理。
- 是否有权限处理。
- 是否有测试。
- 是否更新文档。
- 是否有敏感信息泄露。
